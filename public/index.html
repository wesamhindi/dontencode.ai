Frequently Asked Questions

Everything you need to know about protecting your web app and improving AI search visibility.

How do I install dontencode.ai on my website? ▾

Run npx dontencode.ai init in your project folder, or enable our Cloudflare / Edge proxy in front of your domain with zero code changes.

Does dontencode.ai hurt Google SEO or AI search rankings? ▾

No. dontencode.ai serves clean semantic HTML to verified search crawlers and automatically generates an up-to-date /llms.txt manifest so ChatGPT, Perplexity, and Google AI index your pages accurately.

Why can't I just minify my code or ask an AI coding assistant to fix this? ▾

Minified JavaScript is still readable in browser DevTools, and static code edits cannot issue single-use expiring tokens for your cloud files or block live scraping bursts at the edge.

Which frameworks are supported? ▾

dontencode.ai works with Next.js, React, Nuxt, Vue, SvelteKit, Remix, Astro, Shopify, WordPress, and any custom Node.js, Go, Python, Ruby, or PHP backend.
